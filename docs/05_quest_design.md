# 05. クエスト設計（4階層）

> クエストは EXP の唯一の入口。階層ごとに周期・EXPレンジ・失敗時のコストが異なる。
> 失敗時のペナルティ詳細は `06_penalty.md`。

---

## 1. 4階層の概要

| 階層 | 周期 | EXPレンジ | 個数 | 失敗時 |
|---|---|---|---|---|
| 🗓 **デイリー** | 毎日 | 5〜15 | **固定5個** | HP −10 / EXECUTION −10 / ストリーク0 |
| ⚡ **ゲリラ** | 突発 | 20〜80 | 不定 | HP −25 / 主ステ −(基礎値×50%) / BRIDGE −20 |
| 📜 **ミッション** | 週〜月 | 200〜500 | 1〜3並行 | HP −40 / EXECUTION −(予定EXP×30%) |
| 👹 **ボス** | 月〜四半期 | 400〜1500 | 1体 | HP −50 / 敗北デバフ7日 / 💀敗北ログ |

```
     周期短い ────────────────────────────→ 周期長い
     報酬小                                   報酬大
  ┌──────────┐ ┌────────┐ ┌──────────┐ ┌────────┐
  │ 🗓デイリー │ │ ⚡ゲリラ │ │📜ミッション│ │ 👹ボス  │
  │  5〜15    │ │ 20〜80  │ │ 200〜500 │ │400〜1500│
  │ 毎日固定5 │ │  突発   │ │  週〜月   │ │月〜四半期│
  └──────────┘ └────────┘ └──────────┘ └────────┘
     習慣の維持    割り込み耐性   計画遂行力     到達目標
```

## 2. 🗓 デイリークエスト

### 2.1 仕様

| 項目 | 内容 |
|---|---|
| 個数 | **毎日固定5個**（増減しない） |
| EXP | 1個あたり 5〜15 |
| ストリーク | **5個すべて達成した日のみ**維持。1個でも欠けたら **0 にリセット** |
| 回復 | 全達成で HP **+5 / 日** |
| 入れ替え | **週単位のみ**。**月曜朝に確定し、週中はロック** |

> **ルール**: ストリークは「部分達成」を認めない。4/5 でも 0 にリセットされる。
> これは「毎日必ず全部やる」という一点だけを習慣化の対象にするため。
> UI では**あと何個で途切れるか**を常に強調表示する（`09_dashboard_spec.md`）。

### 2.2 週次ロックの理由と挙動

| 状態 | 挙動 |
|---|---|
| 月曜朝 | その週の5個を確定する。この時だけ変更できる |
| 火〜日 | 🔒 **ロック**。内容を変更できない。UI に「次に選び直せる日」を明示する |

> **設計意図**: 気分でデイリーを差し替えられると、難しいものが永久に後回しになる。
> 週単位で固定することで「今週はこれをやると決めた」というコミットメントを強制する。

### 2.3 Step 1 の仮の5個

> **注意**: 実際の内容は Step 3 で本人にヒアリングして確定する（`01_requirements.md` §10）。
> 以下は画面確認用の仮データ。

| # | 内容 | 主ステータス | EXP |
|---|---|---|---|
| 1 | 技術記事を1本読み、要点を3行で残す | 🧠 INT | 10 |
| 2 | コードを30分以上書く（何でもよい） | 💻 TECH | 15 |
| 3 | 英語の技術文書を10分読む | 🌎 ENGLISH | 8 |
| 4 | 数値を1つ見て気づきを1行残す | 📊 DATA | 8 |
| 5 | 今日やることを朝に3つ決める | 👑 PM | 5 |

Step 1 ダミーでは **3/5 達成**（1・2・5 が達成済み、3・4 が未達）の状態にする。

## 3. ⚡ ゲリラクエスト

| 項目 | 内容 |
|---|---|
| 発生 | 突発。予定外の割り込み（依頼・障害・急な相談） |
| EXP | 20〜80 |
| 期限 | 短い（数時間〜数日） |
| 失敗 | HP −25 / 主ステータス −(基礎値×50%) / 🤝BRIDGE **−20** |

> **ルール**: ゲリラの失敗だけが 🤝BRIDGE に直接ダメージを与える。
> **他者を待たせた**という事実に対するペナルティであり、「橋渡し」能力の毀損として表現する。

- 🚨緊急ボードに**ボスと並べて最上部**に表示する
- **秒まで動くカウントダウン**を出し、残り3日未満で赤く発光させる

---

## 4. 📜 ミッション

| 項目 | 内容 |
|---|---|
| 周期 | 週〜月 |
| EXP | 200〜500 |
| 構造 | **子クエストを持つ**。進捗バーで達成率を表示する |
| 成功 | HP **+20** |
| 失敗 | HP −40 / ⚔️EXECUTION −(予定EXP × 30%) |

- 進行中ミッションは Tab2 に**子クエストの進捗バー付き**で一覧表示する
- 失敗時は 💀敗北ログに墓標として残る

---

## 5. 👹 ボス

| 項目 | 内容 |
|---|---|
| 周期 | 月〜四半期 |
| EXP | 400〜1500 |
| 同時挑戦 | **1体まで** |
| 成功 | HP **+50** + 大報酬（**未決 / Step 3 までに要決定**） |
| 失敗 | HP −50 / 獲得0 / 🔻敗北デバフ（7日 ×0.9） / 💀敗北ログ + **リベンジ対象**として記録 |

> **未確定**: ボス討伐の大報酬が未決。ここが空欄だとボス制度が機能しないため、
> **Step 3 までに必ず決定する**（`01_requirements.md` §10）。

- 🚨緊急ボードの**最上部**。秒まで動くカウントダウン、残り3日未満で赤く発光
- 敗北したボスは 💀敗北ログに「リベンジ対象」として残り、再挑戦できる

## 6. ステータス配分ルール（全階層共通）

| ルール | 内容 |
|---|---|
| 加算先 | **主ステータス1つ + 副ステータス最大1つ**。副は 50% 換算 |
| 構造化 | 関与ステータスが **3つ以上**なら《構造化》発動 + 構造化ボーナス |
| 🤝BRIDGE | **他者が絡むタスクにのみ**設定できる |
| 🔥/⚔️ | **手入力不可**。新規性・完遂実績から自動導出（`04_exp_rules.md` §3） |
| 証拠 | 無ければ **EXP 0** |

## 7. 💀 敗北ログ

失敗した ボス / ゲリラ / ミッション の**墓標**。Tab2 の最下部に置く。

| 記録項目 | 内容 |
|---|---|
| 種別 | 👹ボス / ⚡ゲリラ / 📜ミッション |
| 名称 | 失敗した対象の名前 |
| 日付 | 失敗した日 |
| 被ダメージ | 失った HP と EXP の内訳 |
| リベンジ対象 | 再挑戦可能かどうか（ボスは常に可） |

Step 1 ダミーは **2件**（討伐失敗ボス1 + 失敗ミッション1）。

## 8. 測定期間中の扱い（CALIBRATION PHASE）

| 項目 | 通常 | 測定期間中（14日間） |
|---|---|---|
| クエスト | 4階層すべて | **9ステータス × 各2件 = 18件**の測定用クエスト |
| ペナルティ | 適用 | **完全免除**（HP減少なし・GAME OVERなし） |
| ストリーク | 維持/リセット | **記録のみ**（途切れてもペナルティなし） |
| 目的 | EXPを稼ぐ | **初期Lvを実測する** |

初期Lv算出: `clamp(1..5, round(自己申告点 × 0.4 + 実測点 × 0.6))`

測定する値: 実測時間 / 標準時間の比、完遂率、初挑戦タスクの突破速度、自己申告の経歴

終了時に「覚醒」演出 → 初期ステータス確定 → 固有スキル解放 → 本編開始。

> **未確定**: 18クエストの具体的な中身は Step 3 で GM と一緒に組む（`01_requirements.md` §10）。

## 9. Step 1 ダミーデータ仕様

| 項目 | 値 |
|---|---|
| デイリー | 5個中 **3個達成**（あと2つで途切れる状態） |
| ストリーク | **27日** |
| ボス | **1体挑戦中**（残り **12日**） |
| ゲリラ | 期限切れ間近が **1件**（残り **2日** → 赤く発光する状態） |
| ミッション | 進行中 1〜2件（子クエストの進捗バーが見える状態） |
| 敗北ログ | **2件** |
| 週次ロック | **ロック中**（週中の状態。次に選び直せる日を表示） |
| 測定期間用 | Day **6/14**、18件中 **8件**完了 |
