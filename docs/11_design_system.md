# 11. デザインシステム（ダーク×ネオン）

> **ライトモードは実装しない。** `color-scheme: dark` を固定する。
> チャート実装に着手する前に `dataviz` スキルを読み、配色・軸・凡例の規約をそこに合わせること。

---

## 1. プロダクト分類

| 属性 | 値 |
|---|---|
| プロダクト種別 | パーソナルダッシュボード（Dashboard） |
| ターゲット | 利用者本人1名 |
| 利用デバイス | Responsive（**スマホ 375px 必須**、Desktop 主体） |
| 世界観 | ソロレベリング風の「システムウィンドウ」 |

## 2. スタイル選定

| 項目 | 選定 | 理由 |
|---|---|---|
| UI スタイル | **Dark Mode + Neon Accent** | ゲームのステータス画面という世界観の中核。毎日見たくなる非日常性を出す |
| 補助スタイル | Minimalism + 罫線ベースの構造表現 | 情報量が多い（9ステータス+4階層クエスト+チャート3種）ため、装飾で埋めず罫線で区切る |
| 避けるもの | 多色パレット / 過度な発光 / スキューモーフィズム | 発光を全体に使うと危険信号が埋もれ、HP危険域とカウントダウンの警告が機能しなくなる |

---

## 3. カラーパレット

**アクセントはシアン × バイオレットの2色のみ。** 状態色（緑/黄/赤/紫）は意味を持つ場合にのみ使う。

| 用途 | 色名 | HEX | 使用場面 |
|---|---|---|---|
| Background | Deep Indigo | `#0a0b12` | ページ背景（純黒にしない）。上部にごく淡いグラデーション |
| Surface | Panel | `#11131d` | パネル・カード背景 |
| Surface Raised | Panel Raised | `#171a26` | ホバー・強調パネル |
| Border | Hairline | `rgba(255,255,255,0.08)` | 1px 罫線 |
| Border Accent | Bracket | `rgba(34,211,238,0.35)` | パネル角のブラケット装飾 |
| **Accent 1** | **Cyan** | **`#22d3ee`** | 主アクセント・EXPバー・チャート主系列 |
| **Accent 2** | **Violet** | **`#8b5cf6`** | 副アクセント・チャート副系列・デバフ |
| Text Primary | — | `#e6e9f2` | 本文 |
| Text Secondary | — | `#9aa3b8` | 補助テキスト（コントラスト比 4.5:1 以上を確認済みの値を使う） |
| Text Muted | — | `#6b7490` | 非活性・未解放（**本文には使わない**） |
| HP Safe | Green | `#22c55e` | HP **71〜100** |
| HP Warn | Amber | `#f59e0b` | HP **41〜70** |
| HP Danger | Red | `#ef4444` | HP **0〜40**・期限切迫。**発光あり** |
| Debuff | Violet | `#8b5cf6` | デバフバッジ |
| Ghost | — | `rgba(139,92,246,0.25)` | レーダーの3ヶ月前ゴースト |

> **ルール**: 上記以外の色を追加しない。新しい意味を表現したくなったら、
> **まず罫線・余白・タイポグラフィで解決できないかを検討する**（AC-12 の検証対象）。

### 3.1 チャート配色

| 系列 | 色 |
|---|---|
| TOTAL | Cyan `#22d3ee` |
| 🔥 LEARNING | Violet `#8b5cf6` |
| ⚔️ EXECUTION | Cyan 低彩度 `#67e8f9` |
| 専門7つ（凡例クリックで表示） | シアン〜バイオレット間の**同一色相帯からの明度違い**で生成する |

> **ルール**: 専門7系列に赤・緑・黄を割り当てない（HP と期限警告の意味と衝突するため）。

## 4. タイポグラフィ

| 要素 | フォント | サイズ | ウェイト | 行間 |
|---|---|---|---|---|
| ヒーロー数値（TOTAL Lv） | `ui-monospace` | 48px | 700 | 1.1 |
| H1 / タブ見出し | sans-serif | 28px | 700 | 1.2 |
| H2 / パネル見出し | sans-serif | 18px | 600 | 1.3 |
| 本文 | sans-serif | 16px | 400 | 1.6 |
| キャプション | sans-serif | 13px | 400 | 1.4 |
| **数値全般** | **`ui-monospace`** | 14〜16px | 500 | 1.5 |

> **ルール**: **Lv・EXP・HP・カウントダウン・発動回数・日数はすべて等幅フォント**にする。
> 桁が揃わないと数値が動くたびにレイアウトが揺れ、毎日見るダッシュボードとして耐えられないため。
> 本文は最小 16px。

## 5. パネル（システムウィンドウ）

```
┌─                                        ─┐
   🧬 固有スキル
   ───────────────────────────────────────
   《構造化》 Rank S        Lv 4   ×1.30

└─                                        ─┘
```

| 要素 | 規約 |
|---|---|
| 背景 | `Surface #11131d` |
| 罫線 | 1px `rgba(255,255,255,0.08)` |
| 角 | **ブラケット装飾**（四隅に短い L 字のシアン罫線）。角丸は 4px 以下 |
| 内側余白 | 16px（モバイル）/ 24px（デスクトップ） |
| 見出し | 絵文字アイコン + テキスト。見出し直下に 1px 区切り線 |

## 6. 発光（グロー）の使用制限

> **ルール**: **発光は「カウントダウン（残り3日未満）」と「HP危険域（30以下）」の2箇所のみ**。
> それ以外の要素に `box-shadow` によるグローを付けない。
> 発光が常態化すると警告として機能しなくなる（AC-12 の検証対象）。

| 対象 | 発光 |
|---|---|
| カウントダウン（残り3日未満） | 赤 `#ef4444` のパルス |
| HP バー（`hp <= 40` の危険域） | 赤 `#ef4444` のパルス |
| その他すべて | **なし**（静的な色とボーダーのみ） |

`prefers-reduced-motion: reduce` の場合、**パルスを停止し静的な赤**にする。

## 8. インタラクション

| 要素 | ホバー | トランジション |
|---|---|---|
| タブ | 下線がシアンに / テキスト色を Primary へ | 200ms ease |
| パネル | 罫線の不透明度を上げる | 200ms ease |
| デイリーのチェック行 | 背景を `Surface Raised` へ | 150ms ease |
| チャート凡例 | カーソル pointer + 不透明度変化 | 150ms ease |

> **ルール**: `scale` によるホバーを使わない（レイアウトシフト防止）。
> トランジションは 150〜300ms の範囲に収める。

---

## 9. レスポンシブ

| ブレークポイント | 幅 | レイアウト |
|---|---|---|
| Mobile | 375px | **1カラム**。レーダーは幅いっぱいの正方形。**横スクロール禁止** |
| Tablet | 768px | 1〜2カラム |
| Desktop | 1024px | 2カラム（レーダー + 一覧） |
| Wide | 1440px | 2カラム + `max-width` でセンタリング |

> **ルール**: 375px で**横スクロールが発生しないこと**は受け入れ条件（AC-11）。
> レーダー・チャート・ヒートマップは親幅に追従させ、固定 px 幅を持たせない。
> 数値の桁溢れは等幅フォント + `tabular-nums` で吸収する。

---

## 10. アクセシビリティ

| 項目 | 規約 |
|---|---|
| コントラスト | 本文 4.5:1 以上（`#e6e9f2` on `#0a0b12`）。補助は `#9aa3b8` 以上を使い、`Text Muted` を本文に使わない |
| フォーカス | `focus-visible` で 2px シアンのリング。`outline: none` 単独の使用を禁止 |
| タッチターゲット | 最小 44x44px（タブ・チェック行・凡例） |
| 色以外の手掛かり | HP危険域・期限切迫は**色 + テキストラベル + アイコン**を併用する |
| モーション | `prefers-reduced-motion` でパルス発光とカウントダウンのアニメーションを抑制 |
| セマンティクス | タブは `role="tablist"` / `role="tab"` / `role="tabpanel"`。矢印キーで移動できる |

---

## 11. Do / Don't

| ルール | Do | Don't |
|---|---|---|
| 色 | シアン × バイオレット + 状態色のみ | 系列ごとに新しい色を足す |
| 発光 | カウントダウンとHP危険域のみ | パネル全体・見出し・アクセントに常時グロー |
| 数値 | 等幅フォント + `tabular-nums` | プロポーショナルフォントで桁が揺れる |
| 罫線 | 1px 半透明 + 角のブラケット | 太い枠線・強い角丸 |
| ホバー | 色/不透明度の変化 | `scale` でレイアウトがずれる |
| モバイル | 親幅に追従するチャート | 固定 px 幅で横スクロール発生 |
| ライトモード | 実装しない（dark 固定） | `prefers-color-scheme: light` 対応を足す |

- [ ] シアン × バイオレット + 状態色以外の色が混入していない
- [ ] 発光がカウントダウンとHP危険域の2箇所に限定されている
- [ ] Lv・EXP・HP・カウントダウンがすべて等幅フォント
- [ ] 375px で横スクロールが発生しない
- [ ] 本文コントラスト比 4.5:1 以上
- [ ] タブがキーボード（Tab / 矢印 / Enter）で操作でき、フォーカスリングが見える
