# 07. 固有スキル《構造化》Rank S

> 全ステータスの派生元にあたる中核スキル。ロジックは `src/lib/skill.ts`、閾値は `src/lib/constants.ts`。

---

## 1. 概要

| 項目 | 内容 |
|---|---|
| 名称 | **《構造化》** |
| Rank | **S** |
| 成長軸 | 累積EXPではなく **発動回数** |
| 発動条件 | **3ステータス以上にまたがるタスク**を完了したとき |
| 効果 | EXP計算式の **構造化ボーナス倍率**（1.15 〜 1.50） |
| 表示場所 | Tab1「ステータス」。**レーダーチャートの中心に紋章**、その直下にスキルツリーパネル |

> **設計意図**: 単一分野に閉じた作業では**1ミリも上がらない**。
> 「複数の領域をつないで1つの成果にする」という、このプロダクトが最も伸ばしたい能力そのものを成長軸にする。
> レーダーの中心に置くのは、9軸すべての派生元であるという構造をそのまま図にするため。

---

## 2. 成長テーブル

| Skill Lv | 累積発動回数 | ボーナス倍率 |
|---|---|---|
| 1 | **0** | ×1.15 |
| 2 | **10** | ×1.20 |
| 3 | **25** | ×1.25 |
| 4 | **50** | ×1.30 |
| 5 | **100** | ×1.35 |
| 6 | **150** | ×1.38 |
| 7 | **220** | ×1.41 |
| 8 | **300** | ×1.44 |
| 9 | **400** | ×1.47 |
| 10 | **500** | ×1.50 |

```ts
// src/lib/constants.ts
export const SKILL_ACTIVATION_THRESHOLDS = [0, 10, 25, 50, 100, 150, 220, 300, 400, 500] as const;
export const SKILL_MULTIPLIERS = [1.15, 1.20, 1.25, 1.30, 1.35, 1.38, 1.41, 1.44, 1.47, 1.50] as const;
export const MAX_SKILL_LEVEL = 10;
```

### 2.1 Lv 判定の仕様

- **`activations >= 閾値` を満たす最大の Lv** を返す（レベル曲線と同じ `>=` 判定）
- Lv10 が上限。500回を超えても Lv・倍率は変わらない

| 発動回数 | Skill Lv | 倍率 | 理由 |
|---|---|---|---|
| 0 | 1 | ×1.15 | 初期値。Lv1 から倍率は付く |
| 9 | 1 | ×1.15 | 10未満 |
| 10 | **2** | ×1.20 | 閾値ちょうどで上がる |
| 24 | **2** | ×1.20 | 25未満 |
| 25 | **3** | ×1.25 | 閾値ちょうど |
| 49 | 3 | ×1.25 | 50未満 |
| 50 | **4** | ×1.30 | 閾値ちょうど |
| 52 | **4** | ×1.30 | **Step 1 ダミーデータの値** |
| 99 | **4** | ×1.30 | 100未満 |
| 100 | **5** | ×1.35 | 閾値ちょうど |
| 500 | **10** | ×1.50 | MAX |
| 9999 | 10 | ×1.50 | 上限を超えない |

> **ルール（確定済み）**: 当初のダミー指定「**Lv4 / 発動38回**」は本テーブルと矛盾していた
> （38回は Lv3。Lv4 は50回から）。以下で確定する:
>
> 1. **Lv を JSON に持たせない。必ず発動回数から算出する。** `skill.ts` が唯一の真実の源
> 2. **Step 1 のダミーは発動 52回 → Lv4（×1.30）** とする（「Lv4」という意図を優先）
>
> ダミーJSON に `level` フィールドを持たせてはならない（二重管理になり、ズレると表示が壊れるため）。

### 2.2 次Lvまでの表示

```
残り発動回数 = SKILL_ACTIVATION_THRESHOLDS[currentSkillLv] - activations   // Lv < 10
進捗率 = (activations - 現Lv閾値) / (次Lv閾値 - 現Lv閾値)
```

Lv10 のときは `MAX` と表示し、進捗バーを満杯にする。

## 3. 発動条件の判定

```
shouldActivate(task) = task に関与するステータスの数 >= 3
```

| ケース | 関与ステータス数 | 発動 | 構造化ボーナス |
|---|---|---|---|
| TECH のみ | 1 | ✗ | ×1.0（なし） |
| TECH + INT | 2 | ✗ | ×1.0（なし） |
| TECH + INT + DATA | 3 | **✓** | 現在のSkill Lv の倍率 |
| TECH + INT + DATA + PM | 4 | **✓** | 同上 |

> **注意**: 「関与するステータス」と「EXPの加算先（主1＋副最大1）」は**別概念**（`04_exp_rules.md` §2）。
> 関与が3つでも、EXP が加算されるのは主1＋副1 の最大2つのまま。
> 3つ目以降は**構造化ボーナスの発動条件としてのみ**カウントする。

## 4. 派生ツリー

対応する専門ステータスが閾値に達すると**自動解放**される。常時効果として該当ステータスの EXP **+10%**。

| 派生 | 解放条件 | 常時効果 |
|---|---|---|
| 《データ分析》 | 📊 DATA **Lv5** | DATA の獲得EXP +10% |
| 《AI開発》 | 💻 TECH **Lv5** | TECH の獲得EXP +10% |
| 《システム設計》 | 💻 TECH **Lv7** かつ 🧠 INT **Lv5** | TECH の獲得EXP +10% |
| 《PM》 | 👑 PM **Lv5** | PM の獲得EXP +10% |
| 《現場との橋渡し》 | 🤝 BRIDGE **Lv5** | BRIDGE の獲得EXP +10% |

### 4.1 最終クラス

> **全5派生の解放が、最終クラス《AIビジネスアーキテクト》の到達条件**。

UI では未解放の派生を**条件付きでグレーアウト表示**し、「あと何が必要か」を常に見えるようにする
（隠さない。次に何をすべきかを画面から読み取れることが目的のため）。

### 4.2 判定仕様

```ts
// 判定は「現在のステータスLv」から毎回導出する（解放フラグを永続化しない）
isUnlocked(derivation, statuses) => boolean
```

- **解放状態は保存せず、常にステータスLvから算出する**。GAME OVER で Lv が1に戻れば派生も自動的に未解放へ戻る
- 《システム設計》は **AND 条件**（TECH Lv7 **かつ** INT Lv5）。片方だけでは解放しない

| ケース | TECH | INT | 《AI開発》 | 《システム設計》 |
|---|---|---|---|---|
| A | 4 | 9 | ✗ | ✗ |
| B | 5 | 4 | **✓** | ✗ |
| C | 7 | 4 | **✓** | ✗（INT不足） |
| D | 6 | 5 | **✓** | ✗（TECH不足） |
| E | 7 | 5 | **✓** | **✓** |

## 5. UI 仕様（Tab1）

### 5.1 紋章（レーダー中心）

- 九角形レーダーの**中心**に配置する
- Skill Lv に応じて紋章の輝度・装飾を段階的に変える（シアン×バイオレットの範囲内）
- 測定期間中（`phase === "calibration"`）は**未解放状態**として暗く表示し、「覚醒後に解放」と示す

### 5.2 スキルツリーパネル（紋章の直下）

```
┌─ 🧬 固有スキル ────────────────────────────┐
│  《構造化》  Rank S          Lv 4  ×1.30   │
│  発動回数 52 回   ─────────▁▁▁  次Lvまで 48 │
│                                             │
│  派生                                       │
│   ✓ 《データ分析》      DATA Lv5      +10%  │
│   ・《AI開発》          TECH Lv5   (現 Lv4) │
│   ・《システム設計》    TECH Lv7 + INT Lv5  │
│   ・《PM》              PM   Lv5   (現 Lv3) │
│   ・《現場との橋渡し》  BRIDGE Lv5 (現 Lv2) │
│                                             │
│  最終クラス《AIビジネスアーキテクト》 1/5   │
└─────────────────────────────────────────────┘
```

- 解放済みは `✓` + 通常色、未解放は `・` + グレーアウト + **現在値の併記**
- 数値（Lv・回数・倍率）は**等幅フォント**で桁を揃える

| # | 項目 | 期待 |

| U-1 | Lv境界 | 24回→Lv2(×1.20) / 25回→Lv3(×1.25) |
