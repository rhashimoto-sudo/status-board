## 1. 確定している報酬（Step 1 で実装済みになるもの）

現時点で「報酬」として実際に機能しているのは、以下のゲーム内リソースのみ。

| 報酬 | 内容 | 実装 |
|---|---|---|
| EXP | クエスト完了で各ステータスに加算 | `04_exp_rules.md` |
| Lv / 称号 | 累積EXPの閾値到達で昇格（計90称号 + 総合10） | `03_status_system.md` |
| HP 回復 | デイリー全達成 +5/日 / ミッション完遂 +20 / ボス討伐 +50 | `06_penalty.md` §2.1 |
| 🔥ストリーク | デイリー5個全達成で継続 | `05_quest_design.md` §2 |
| 《構造化》Lv | 3ステータス以上に跨るタスクで発動回数が増える | `07_unique_skill.md` |
| 派生スキル解放 | 専門ステータスが閾値到達で自動解放。**該当ステータス EXP +10%** | `07_unique_skill.md` §4 |
| 最終クラス | 派生5種すべて解放で《AIビジネスアーキテクト》 | `03_status_system.md` §3.2 |
| 🏛殿堂入り | GAME OVER 時に周回記録を永久保存 | `06_penalty.md` §5.2 |

> **注意**: 上記のうち「派生スキルの EXP +10%」だけが**ゲーム内の恒常的な強化**として機能する。
> 他はすべて記録・表示であり、次の行動を有利にする効果を持たない。

## 2. ⚠ 未決の最重要事項: ボス討伐の大報酬

> **未決。空欄だとボス制度が機能しないため、Step 3 までに必ず決定する**
> （`01_requirements.md` §6）。

現状の問題:

- ボスは **EXP 400〜1500** と **HP +50** しか返さない
- 一方で失敗時は **HP −50 + 敗北デバフ7日 + 敗北ログ** と重い
- **リスクに対してリターンが釣り合っていない**ため、合理的に考えるとボスを避けるのが最適解になってしまう

決めるべきこと:

| 論点 | 選択肢の例 |
|---|---|
| 報酬の種類 | ゲーム内（強化・称号・実績）か、**現実の報酬**（買い物・休暇など自分への約束）か |
| 大きさ | 失敗リスク（HP−50 + 7日デバフ）を上回る水準はどこか |
| 頻度 | 月〜四半期に1体という周期に対して妥当か |
