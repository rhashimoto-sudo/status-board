## A. src/lib/titles.ts — `totalTitleFor` が非整数 Lv で `undefined` を返していた（実バグ）

**操作**: 修正

`clampLevel` が `Math.min(10, Math.max(1, level))` だけで整数化しておらず、`clampLevel(3.9)` は
`3.9` をそのまま返していた。その結果 `TOTAL_TITLES[3.9 - 1]` = `TOTAL_TITLES[2.9]` が
**`undefined`** になる。

`computeTotalLevel`（`src/lib/level.ts`）は仕様どおり小数を返し（画面表示も `3.9`）、
`totalTitleFor` の実質唯一の呼び出し元がその小数。戻り値の型は `string` なのに実際は `undefined` が
返り、`hero-header.tsx` の `totalTitle ?? "???"` が吸収するため、
**メインフェーズで総合称号が常に `???` になっていた**。team-lead がブラウザで実測して確認した実バグ。

**丸め方向は切り捨て（floor）を採用した。** 根拠は
`docs/03_status_system.md` §3.2「総合称号 = `TOTAL_TITLES[floor(TOTAL Lv) - 1]`」と
`docs/09_dashboard_spec.md:59`「`totalTitleFor(floor(totalLv))`」の2つ。
どちらも floor を明示しているため、切り上げ・四捨五入は採らなかった。

修正は `clampLevel` に `Math.floor` を入れる1箇所のみ。`titleFor` も同じ経路を通るため併せて直った。

### src/test/titles.test.ts
**操作**: 修正
既存テストは**全て整数入力**だったためこのバグをすり抜けていた。非整数入力の回帰テストを追加した:

- `totalTitleFor(3.9)` が `totalTitleFor(3)` と一致し `undefined` にならない
- `titleFor("INT", 4.7)` が `titleFor("INT", 4)` と一致する
- 下限側 `0.5` → Lv1 の称号、上限側 `10.9` → Lv10 の称号（`totalTitleFor` / `titleFor` の両方）

> **教訓**: 「境界値テスト」を整数境界だけで組むと、実際の呼び出し元が小数を渡す関数の
> インデックス破綻を検出できない。呼び出し元が返す値の**型と定義域**（`computeTotalLevel` は
> 小数を返す）からテスト入力を決めるべきだった。

## B. src/components/status/status-radar.tsx — `🔥 LEARNING` の左端 2px はみ出し

**操作**: 修正

実測で `overflowLeftPx: 2`。`outerRadius` を **58% → 55%** に縮小して解消した。

**他8軸のクリップを再発させない根拠**: 9軸は `startAngle=90` から時計回り40°刻み（`STATUS_ORDER` 順）で
配置され、各軸の水平オフセットは `radius * cos(angle)` で決まる。左端に最も寄るのは LEARNING
（角度170°、`cos ≈ -0.985`）。**半径を縮めると全軸のオフセットが一様に中心へ寄る**ため、
直前に解消した `📣 MARKETING`（右端）・`🧠 INT`（上部）の余白はむしろ広がる方向にしか動かない。

`ResponsiveContainer` の使用と固定px幅なし（C-20, AC-13）は維持している。

## C. 背景を近未来的な意匠に刷新（system window 風）

### 追加した CSS 変数（`@theme` 内）

| 変数 | 値 | 用途 |
|---|---|---|
| `--color-bg-grid-line` | `rgba(34, 211, 238, 0.05)` | 微細なグリッド線・スキャンライン |
| `--color-bg-vignette` | `rgba(5, 6, 10, 0.6)` | 四隅を沈めるビネット |

| `--color-bg-edge-violet` | `rgba(139, 92, 246, 0.14)` | 下端のバイオレットの縁光 |

すべて既存アクセント（シアン `#22d3ee` / バイオレット `#8b5cf6`）と背景トーンの
低不透明度のみで構成しており、**新しい色相を増やしていない**。

### 使った手法（`box-shadow` を一切使わない）

1. **微細なグリッド**: `linear-gradient` 2本（縦横）を `background-size: 48px 48px` でタイル
2. **ビネット**: `radial-gradient(ellipse at center, transparent 55%, …)`
3. **ノイズ**: `feTurbulence` の SVG data URI（`baseFrequency=0.85`, alpha `0.03`）。
   外部画像・CDN は使っていない
4. **縁の光**: `body::before`（`position: fixed; inset: 0; z-index: -1`）に上下方向の
   `linear-gradient` のみ。**グローではなくグラデーションで表現している**
5. **スキャンライン**: `body::after` に低不透明度（0.25）の帯を `14s linear infinite` で流す

### 制約の遵守（司令塔が grep で実測確認）

| 制約 | 実測結果 |
|---|---|
| `box-shadow` を増やさない（AC-14） | `grep -rn "box-shadow" src/` が**4行のまま**（`@keyframes danger-pulse` 2 / `.danger-glow` 1 / `prefers-reduced-motion` 上書き 1）。すべて HP 危険域・カウントダウン共用のグローに属し、構成は変わっていない |
| コンポーネントへの色 `#` 直書き禁止 | `grep -rnE '#[0-9a-fA-F]{6}' src/components/` の該当は `skill-emblem.tsx:7` の**コメント1件のみ**（説明文中の `#8b5cf6`）。実コードは0件 |
| `color-scheme: dark` 固定 | 変更なし（`globals.css:4`） |
| `prefers-reduced-motion` | スキャンラインの `animation: none` かつ `opacity: 0` に落とす |
| 375px 横スクロール | 装飾は `position: fixed; inset: 0; pointer-events: none` の疑似要素のみでドキュメント幅を広げない |
| 可読性 | 装飾は `z-index: -1` で常に本文の背後。パネルは不透明な `--color-surface` 系で覆われるため、`skill-emblem.tsx` の `MAX_GLOW_OPACITY = 0.5` によるコントラスト是正を打ち消さない |
